# SARVESH M — Portfolio

Professional portfolio and resume website.

## Identity
**Finance × Creative × Digital**

## Stack
- HTML
- CSS
- JavaScript
- GitHub for source control
- Vercel for deployment

## Run locally
Open `index.html` in a browser.

## Deploy
Import this GitHub repository into Vercel. No build command is required because this is a static frontend.

## Content areas
- About
- Experience
- Finance education
- Creative practice
- Education
- Contact

Future upgrades can include project imagery, CMS content, a contact backend, analytics, and a custom domain.
